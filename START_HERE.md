# С чего начать — BardoCompute

[Главная](README.md) · [Исследования](RESEARCH_INDEX.md) · [Правила](REPOSITORY_GUIDE.md)

## Хочу использовать

Начни с закреплённого программного/аппаратного reference `f50490e8194f0e5c7aeeba251f2575eb8155ed54`. Команды запуска есть в README. Это материал для воспроизведения и разработки, не промышленный процессор. Отдельный worktree позволяет работать с кодом, не превращая главную страницу в очередную исследовательскую ветку.

## Хочу исследовать

Выбери один трек в RESEARCH_INDEX.md: базовая алгебра, BARDO-TX1, LOGOS/HYBRID или исследования восстановления. Сначала прочитай гипотезу, контроль, результаты и ограничения соответствующего PR. Номер версии в названии ветки сам по себе не означает, что она заменяет остальные ветки.

## Хочу понять, что доказано

У BARDO-TX1 есть опубликованное свидетельство симуляции и инструментальной FPGA-реализации на точном коммите. Оно не доказывает физическую работу платы, энергопотребление или превосходство над CPU. LOGOS/HYBRID имеет отдельные синтетические эксперименты; их нельзя выдавать за результат железа.

## Что изменено при наведении порядка

В main добавлен навигационный слой, единые статусы и снимок 34 существовавших веток. Исследовательский код не объединён автоматически. Старый README сохранён. Две ветки с одинаковым SHA отмечены как совпадающие указатели, но не удалены: одинаковый SHA не доказывает, что название и обсуждение больше не нужны.

Следующая содержательная консолидация — отдельный reviewed PR с выбранным reference-кодом, его тестами и явными исключениями. Это не часть переоформления документации.
