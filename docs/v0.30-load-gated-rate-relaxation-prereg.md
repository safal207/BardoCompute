# v0.30 Load-Gated Rate Relaxation — preregistration

Status: **frozen before implementation/results**.

## Prior evidence

v0.29 diagnostic attribution on the already-spent v0.28 family found, on both Python 3.11 and 3.12:

- every failed RATE_RELAXED challenge occurred in an externally labeled active-stress phase;
- no failed RATE_RELAXED challenge occurred in recovery/drain;
- successful RATE_RELAXED attempts had median LOAD ≈ 0.34;
- failed RATE_RELAXED attempts had median LOAD ≈ 0.54;
- PAIN could be zero immediately before a failed challenge.

No threshold was selected from v0.29. The v0.28 seeds remain spent and diagnostic-only.

## Hypothesis

The existing v0.19 `MIN_ACTIVE_LOAD = 0.50` threshold can act as a phase-blind readiness veto for RATE relaxation: even when bounded resolution evidence is sufficient, do not challenge the RATE cap while measured LOAD remains at or above the already-frozen active-load threshold.

This tests whether low supported PAIN plus accumulated resolution evidence needs an explicit low-load condition before withdrawing RATE protection.

## Frozen controller change

Start from v0.28 `RateFirstRecoveryMembrane` unchanged except for one readiness condition.

Existing v0.28 transition:

```text
FULL_PROTECTION
  AND resolution_strength >= RECOVERY_DWELL
    -> RATE_RELAXED
```

v0.30 transition:

```text
FULL_PROTECTION
  AND resolution_strength >= RECOVERY_DWELL
  AND LOAD < MIN_ACTIVE_LOAD
    -> RATE_RELAXED
```

Where both constants are already frozen from v0.19:

```text
RECOVERY_DWELL = 2
MIN_ACTIVE_LOAD = 0.50
```

No new threshold is introduced.

All other semantics remain exactly v0.28:

- entry predicate = frozen v0.19;
- resolution accumulator = exact v0.22 (`healthy -> +1`, `severe -> -1`, intermediate -> hold);
- RATE is withdrawn before RELIEF;
- RATE_RELAXED challenge lasts exactly one completed epoch;
- RELIEF_WITHDRAWAL challenge lasts exactly one completed epoch;
- ROUTE/RATE/RELIEF/STORAGE actuator magnitudes unchanged;
- no admission shedding;
- no phase labels available to the controller.

```text

RATE_RELAXED attempts / successes / failures
```

Internal self-state is not the external health judge.

## Preregistered promotion bar

v0.30 is promotable only if the full existing v0.19 outcome/selectivity bar holds:

```text
median completed / baseline                 >= 1.25
median lost / baseline                      <= 0.75
median seconds-per-completion / baseline    <= 1.15
median deadline-miss epochs / baseline      <= 0.60
median severe-miss epochs / baseline        <= 0.25
median terminal backlog                     == 0
all digest mismatches                       == 0

median RELIEF occupancy                     <= 0.65
median STORAGE occupancy                    <= 0.65
median RELIEF occupancy / R2                <= 0.75
median STORAGE occupancy / R2               <= 0.75

median completed / R2                       >= 0.98
median deadline-miss epochs / R2            <= 1.25
median seconds-per-completion / R2           <= 1.15
```

Additionally, relative to frozen v0.28 on the same fresh family:

```text
median missed_work_fraction(v0.30) <= median missed_work_fraction(v0.28)
median failed RATE_RELAXED challenges(v0.30) < median failed RATE_RELAXED challenges(v0.28)
median STORAGE occupancy(v0.30) <= median STORAGE occupancy(v0.28)
```

The LOAD veto may not earn promotion merely by suppressing challenges; it must preserve or improve external service quality and storage recovery.

## Falsification

If v0.30 fails:

- retain the result;
- do not tune `MIN_ACTIVE_LOAD`, `RECOVERY_DWELL`, PAIN thresholds, or actuator magnitudes on these seeds;
- distinguish whether the LOAD veto delays recovery too much, leaves false positives, or simply shifts the bottleneck to RELIEF/STORAGE;
- do not introduce a new signal from these seeds without a separate diagnostic step.

## Narrow claim allowed by PASS

> On this executed fault-injected work queue, the already-frozen active-load threshold provided a phase-blind veto against premature RATE withdrawal and preserved the preregistered external outcome/selectivity bar on a fresh workload family.

No biological, emotional, conscious, or neuroscience-equivalence claim follows from any result.
